// learnings.log

What this internship actually taught me.

Logged like commits — the small realizations that added up over the course of the internship.

  1. a1c9f2e

    Real code is read far more than it's written

    Naming things clearly and leaving small comments saved my reviewers — and future me — a lot of time.

  2. 7de401b

    Responsive design isn't an afterthought

    Building mobile-first from the start avoided messy overrides later — I now sketch layouts for small screens first.

  3. f930aa8

    Git branches are for communication, not just backups

    Small, focused pull requests with clear descriptions got reviewed faster and caused fewer merge conflicts.

  4. 2b56c14

    "It works" and "it's done" are different things

    Edge cases, loading states, and error messages are part of the feature, not extras to add "if there's time."

  5. e88d073

    Asking early beats guessing for two days

    A five-minute question to a senior developer regularly saved me from going down the wrong path entirely.
